# Автоматичні ціни та залишки

Локальний сервер на порту 8790 оновлює дані при запуску та кожні 15 хвилин, доки працює процес `server.mjs`. Перед оформленням стандартних товарів дані старші за 2 хвилини оновлюються повторно. При недоступності джерела таке оформлення зупиняється з поясненням; кошик залишається.

Джерело SQL використовується лише для читання. Автоматичне оновлення змінює ціни та залишки вже завантажених комплектацій у локальному Saleor, зберігає власні ціни, описи та деактивацію. Нові моделі, їх параметри й фотографії додаються окремим повним імпортом `integration/sync-vsmarket-catalog.mjs`.

Доступна кількість у поточному регістрі вже враховує резерв: резерв показуємо окремо, повторно не віднімаємо. Нульові залишки теж оновлюються. Замовлення з сайту є запитом на підтвердження менеджером та не створює резерву в обліковій системі.

Для іншого порту або майбутнього сервера: `CATALOG_AUTO_SYNC=1`; для вимкнення: `CATALOG_AUTO_SYNC=0`. Наявні локальні SQL та Saleor налаштування потрібні на тому комп’ютері, де працює оновлення. `saleor-local-api.mjs` наразі налаштовано на локальний API — перед Linux розгортанням його адресу треба налаштувати.

Дата оновлення в каталозі відповідає успішно завантаженому знімку. При зміні ціни під час вибору покупець має оновити оформлення та підтвердити нову суму.
