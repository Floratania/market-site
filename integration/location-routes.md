# Найближча точка за автомобільним маршрутом

Порівнюємо відстані автомобільних маршрутів від одного початку до двох перевірених магазинів. Обирається менша довжина маршруту, не відстань по прямій і не найменший час. Тривалість приблизна, без актуальних заторів. Сервіс планує рекомендований маршрут; це не гарантія найкоротшого з усіх можливих доріг.

## Підключення

Скопіюйте `routing.example.json` у `routing.local.json` (файл уже створено локально). Він виключений із Git і не віддається браузеру.

- Власний OSRM: `provider: "osrm"`, `osrmBaseUrl` — адреса вашого сервісу з автомобільним профілем і картою регіону. Потрібен Table API з `distance,duration`. Публічні демонстраційні сервери OSRM заборонені адаптером: їхні правила обмежують комерційне використання.
- Google: `provider: "google"`, `googleApiKey` — ключ Routes API із обмеженнями для цього сервера. Можна також задати `GOOGLE_ROUTES_API_KEY`. Адаптер використовує Compute Route Matrix, DRIVE, TRAFFIC_UNAWARE. Перед публікацією додайте умови використання й політику приватності, потрібні Google Maps Platform. Ключ, підключення білінгу й ліміти Google налаштовує власник.

Конфігурація перечитується без перезапуску. Після її зміни оновіть сторінку. Без налаштованого сервісу сайт повідомляє, що автоматичне порівняння недоступне, та залишає ручний вибір/Google Maps.

## Дані та відмови

Геолокацію запитуємо лише після натискання кнопки. Поруч є пояснення передачі координат обраному сервісу. POST `/api/location-routes` передає тільки latitude/longitude; адреси призначення беруться з конфігурації магазину. Координати відвідувача не записуються у файли, URL сайту або журнали. Посилання Google Maps не містять його координат; Google вибирає початок маршруту окремо.

Сервер перевіряє координати, обмежує запити (20 на годину на IP), використовує timeout і не передає ключ у браузер. Порівняння приймає тільки повну відповідь із двома різними адресатами. Неповна відповідь, timeout або помилка не замінюються прямою відстанню. Для відсутнього маршруту показуємо відповідний текст; для грубої геолокації — невизначеність.

Перевірки: `node --test tests/locations.test.mjs`; `node integration/verify-location-routes.mjs` для локального API. Модульні перевірки імітують відповіді провайдерів. Реальні маршрути не перевірені до підключення сервісу.
