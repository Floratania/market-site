# Точки VS Market у футері

Адреси, телефони, координати та placeId звірені 8 жовтня 2026 року з окремими картками Google Maps із наданого користувачем пошуку:

- Мамаївці: вул. Шевченка, 2-В; 48.3452003, 25.8614261; `ChIJsd5FZgAHNEcRTjdi3uJYwYM`.
- Буда: вул. Київська, 13; 48.299156, 26.0171438; `ChIJFSLjjjUJNEcRWo3NIkxYgCI`. Адреса також підтверджена офіційним https://vs.market/.

iframe URLs отримані з Google Maps → Поділитися → Вставити карту. Публічні контакти зберігаються в `site-content.json`, передаються через `/api/site` після валідації. Не ототожнювати точку Буда зі складом Магала без окремого підтвердження.

Спільний `locations.js` працює на головній, каталозі, сторінках моделей та акаунта. Початково вибрана перша точка; її не позначаємо найближчою. Найближча точка визначається за довжиною автомобільного маршруту через налаштований Google Routes API або OSRM. Порівняння по прямій більше не використовується. Налаштування та перевірки описані в [location-routes.md](location-routes.md).

Геолокація запитується тільки після натискання «Знайти найближчу за маршрутом», якщо сервіс налаштований. Координати передаються сервісу маршрутів через локальний сервер, не зберігаються в акаунті чи localStorage і не включаються в Google Maps route URL. За неточної геолокації показується попередження. При неналаштованому сервісі, забороні або помилці залишається ручний вибір. Для геолокації на сервері потрібен HTTPS; localhost підтримується браузерами.
