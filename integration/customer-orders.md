# Кабінет: телефон та замовлення

`/account` — ім’я, прізвище та телефон. Номер зберігається в metadata користувача Saleor, ключ `storefront_phone`. Профіль синхронізується між пристроями, номер підставляється під час оформлення.

`/account/orders` — замовлення локального checkout, які оформлено з активного акаунта. Сервер бере ID користувача лише з перевіреної сесії та зберігає `customerId` разом із замовленням. API `/api/account/orders` повертає тільки замовлення цього ID, без службових даних сповіщень і контактів інших покупців.

Попередні гостьові замовлення автоматично не прив’язуються за email чи телефоном. Ці поля покупець може вказати довільно, тому така прив’язка розкривала б чужі замовлення.

Статус «Отримано магазином» означає збереження у локальному сховищі. Надсилання повідомлень менеджеру, оплата, резервування та перевезення мають окремі стани і тут не видаються за виконані.
